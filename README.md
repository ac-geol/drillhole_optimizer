# Drillhole Optimizer

Infill drilling budget optimiser. See `Infill Drilling Budget Optimiser Build Spec.md` for the full build specification.

## Data policy

- `data/test/` — small synthetic or sample datasets, tracked in git.
- Everything else under `data/` is git-ignored. Real project data must never be committed.

## Setup

```bash
python3 -m venv .venv
source .venv/bin/activate
```
